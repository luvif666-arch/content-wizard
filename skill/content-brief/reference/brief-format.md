# 创作简报的标准格式

## 格式

```markdown
# 创作简报

> 标题：<选定的一句标题>

## 关系｜这条内容是给谁看的？
- 给谁看：<受众>
- 这意味着：<这个选择的含义>

## 话题｜你想聊哪个大方向？
- 大方向：<大类>
- 范围收窄到：<子话题，最多 2 个>

## 选题｜这次你要对谁说什么？
- 对谁说：<具体的人>
- 说什么：<具体的事>

**这次不讲**
- <范围外的内容 1>
- <范围外的内容 2>

**这次必须给到**
- <读者看完要能回答的那句话>
- <至少一个能立刻用上的判断或动作>

## 切入点｜这次从哪里开始聊？
1. [<类型>] <具体的入口描述>
2. [<类型>] <具体的入口描述>

## 标题｜用哪句话开启这段对话？
- 标题：<选定的一句>
- 句式：<问题式 / 判断式 / 共鸣式>
- 为什么是它：<这句话在邀请谁进来、为什么他会想点开>

## 表达｜你准备用什么让对方理解你的判断？
- 体裁：<图文 / 口播视频 / 多图轮播>
- 结构顺序：
  1. 场景——让对方先认出现象
  2. 解释——回答为什么值得在意
  3. 具体建议——让对方下次做决定时用得上
- 体裁追问：
  - <追问 1> <回答>
  - <追问 2> <回答>
```

## 完整示例

```markdown
# 创作简报

> 标题：第一次约会，找个能好好说话的地方。

## 关系｜这条内容是给谁看的？
- 给谁看：完全陌生的人
- 这意味着：需要从头建立语境，不能跳步，也不要假设他知道任何背景。

## 话题｜你想聊哪个大方向？
- 大方向：情感
- 范围收窄到：约会、第一次见面

## 选题｜这次你要对谁说什么？
- 对谁说：第一次见网友的人
- 说什么：怎么让这次约会聊得舒服，让对方愿意继续了解你

**这次不讲**
- 与「怎么让约会聊得舒服」无关的周边知识：约会穿搭、送礼、长期关系经营，这一篇不展开
- 只有正确但没有信息量的常识：例如「要准时」「要有礼貌」，读者默认知道的部分不再重复
- 需要长期相处才能谈的部分：磨合、冲突处理，留给后续内容

**这次必须给到**
- 让读者看完能回答一句话：第一次约会该把环境选成什么样
- 至少一个能立刻用上的判断：订位前先确认这家店能不能正常对话

## 切入点｜这次从哪里开始聊？
1. [具体场景] 从「选哪家餐厅」开始：环境决定了这次见面能不能聊起来
2. [极小细节] 从「面对面还是并排坐」这个小选择开始

## 标题｜用哪句话开启这段对话？
- 标题：第一次约会，找个能好好说话的地方。
- 句式：判断式
- 为什么是它：判断式先给结论，正在准备第一次约会的人会带着「凭什么」的疑问点进来，正文负责解释为什么环境比菜重要。

## 表达｜你准备用什么让对方理解你的判断？
- 体裁：图文
- 结构顺序：
  1. 场景——很吵的餐厅里每句话都要重复一遍，刚接上的话又被打断
  2. 解释——初次见面本来就在互相了解，方便交流的环境能让对话继续
  3. 具体建议——订位前先确认的三件事
- 体裁追问：（图文无追加追问）
```

## 输出时注意

- **六个区块必须齐全。** 缺哪个就说清哪个是空的，不要静默省略。
- **不要合并区块。** 选题和切入点分开写，它们的职责不同：选题决定说什么，切入点决定从哪进来。
- **理由那一行不能省。** 标题只给句子不给理由，等于把判断又推回给用户。
- **Markdown 格式**，让用户能直接复制到笔记、编辑器或另一个 AI 对话框里。
