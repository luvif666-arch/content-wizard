# 候选与模板参考

**先读这一节，再往下用。**

## 灵感示例怎么写才对（第 3 步最要紧）

用户在这一步最容易卡死：抽象的处境类型给不出具体的人和事。所以拿到子话题后，主动给 4–6 个**结合这个话题**的具体的人和事。

三条硬要求：

1. **针对当前话题，不要通用标签。**
   - ❌ 「第一次做的人不知道怎么办」——等于没说
   - ✅ 「马上要第一次见网友，不知道该准备什么，怕全程冷场」——有处境、有张力
2. **覆盖不同处境**，不要六条都是同一类人。
3. **优先挑有人真的问过的小众问题或矛盾处境**，而不是人人都知道的大道理。

**这些示例主要靠你的领域知识现想，不要照抄下面的表。** 下面的表只是保底，用于两种情况：话题太偏、或者你一时想不出。

没有联网检索能力时，用自己的知识推导即可，**但不要假装查过网**。

### 可直接套用的张力类型

想不出角度时，按这六类各想一个，通常就能凑够 4–6 条：

| 张力类型 | 他在经历什么 |
|---|---|
| 第一次面对 | 不知道从哪下手，怕一上来就选错方向 |
| 反复卡住 | 试过好几轮，每次都在同一个地方停住 |
| 难以抉择 | 面前有几个做法各有道理，需要判断依据而不是更多建议 |
| 结果落差 | 照着普遍说法做了，结果和说的完全不一样，开始怀疑自己 |
| 主流建议不适用 | 他的条件（时间／预算／家庭状况）跟主流建议都对不上 |
| 信息不对称 | 信息又碎又互相矛盾，没法判断谁说得对，也怕踩坑 |

## 受众选项（第 1 步）

**说明文案一律用第二人称**，不要出现指代不明的「我」。

| 选项 | 说明 | 这个选择意味着 |
|---|---|---|
| 完全陌生的人 | 他对你和你做的事一无所知 | 需要从头建立语境，不能跳步，不要假设他知道任何背景 |
| 已关注我的人 | 他知道你是谁，也愿意听你说 | 可以直接进入观点，不必再铺垫身份和资历 |
| 同行的从业者 | 你们有共同背景和经验 | 可以省略基础概念，直接讨论分歧点和判断依据 |
| 潜在客户 / 有具体需求的人 | 他带着问题来找答案 | 以解决问题为优先，少讲情怀，多给可执行的判断 |
| 熟人 / 朋友 | 你们关系亲近，他接受口语化表达 | 可以用内部梗和更松弛的语气，不必端着 |

## 大类话题 → 子话题（第 2 步）

命中时直接用，保证同一类话题每次给的建议稳定；没命中就按这个方向现推 4 个具体分支。

| 大类 | 子话题候选 |
|---|---|
| 情感 / 恋爱 | 约会、暧昧期、长期关系、分手与复合、婚姻磨合、如何认识一个人 |
| 职场 / 职涯 | 求职、转行、晋升、汇报与沟通、副业、和老板相处 |
| AI / 人工智能 | 工具选型、提示词写法、工作流自动化、AI 对岗位的影响、学习路径、常见误区 |
| 健康 | 睡眠、饮食结构、运动习惯、情绪管理、体检解读、久坐问题 |
| 消费 | 品牌选择、性价比判断、踩坑复盘、情绪消费、收纳整理、送礼 |
| 自媒体 | 起号、选题方法、涨粉、变现、内容复盘、账号定位 |
| 内容创作 | 选题方法、标题写法、切入点、内容复盘、创作节奏、素材积累 |
| 写作 | 选题、结构、开头、修改、素材积累、写作习惯 |
| 理财 | 记账、储蓄、基金定投、风险识别、收入结构、大额支出 |
| 育儿 | 睡眠、喂养、情绪引导、亲子沟通、入园适应、习惯培养 |
| 教育 | 学习方法、专注力、亲子沟通、升学选择、兴趣培养、考试焦虑 |

没命中的方向，用这些通用后缀现推：`的入门`、`的常见误区`、`的真实成本`、`的第一步`、`的长期影响`、`的选择标准`。

## 具体的人（第 3 步的处境分类）

| 处境 | 他关心什么 |
|---|---|
| 第一次做这件事的人 | 担心做错、不知道该准备什么 |
| 做过很多次却一直卡住的人 | 想搞清楚为什么总停在同一阶段 |
| 正在做选择、拿不定主意的人 | 需要判断依据，而不是更多信息 |
| 已经做了但结果不好、在怀疑自己的人 | 需要解释原因和修正方向 |

## 切入点类型（第 4 步）

| 类型 | 模板（`{}` 换成选题的领域名词） |
|---|---|
| 具体场景 | 从一个最常见的具体场景开始：讲「{}」时，大多数人第一步会做什么、卡在哪 |
| 普遍误区 | 从一个人人都信但其实是错的做法开始：越努力做某件事，结果反而越差 |
| 一次踩坑 | 从一次真实踩坑开始：看起来准备得很充分，最后还是没得到想要的结果 |
| 两类人对比 | 从两类人的对比开始：一类总是做不成，另一类很轻松，差别不在努力程度 |
| 极小细节 | 从一个极小但决定成败的细节开始：一个几乎没人注意的选择，直接改变了结果 |
| 一个时间点 | 从一个具体的时间点或收尾动作开始：事情结束之后，那个决定性的动作做没做 |

## 标题句式（第 5 步）

| 句式 | 写法 | 例子（以「第一次约会」为例） |
|---|---|---|
| 问题式 | 把读者正在做的那次选择直接摆出来 | 第一次约会，到底应该去哪里吃饭？ |
| 判断式 | 先给结论，正文负责解释为什么 | 第一次约会，找个能好好说话的地方。 |
| 共鸣式 | 从一个容易代入的失败经历开始 | 餐厅选得很认真，第一次约会还是没聊起来。 |

## 表达结构（第 6 步）

默认三段：

1. **场景**——让对方先认出现象
2. **解释**——回答为什么值得在意
3. **具体建议**——让对方下次做决定时用得上

体裁追问：

- 口播视频：哪些地方需要画面演示？哪些段落可以剪短？
- 多图轮播：哪几页各承担一个信息点？哪一页必须放在第一张？

## 抽取「领域名词」的规则

拼接切入点和标题模板时，从「具体的事」里抽一个可复用的名词：

1. 去掉句末标点
2. 如果句子里有逗号或句号，取最后一个分句
3. 长度落在 4–18 字之间就用它，超过 26 字截断加省略号
4. 都取不到就退回用第 2 步选的子话题

例：「怎么让这次约会聊得舒服，让对方愿意继续了解你」→ 取最后分句 → 「让对方愿意继续了解你」。
