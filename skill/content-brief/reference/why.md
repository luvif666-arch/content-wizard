# 每一步背后的判断依据

被问到「为什么要这样拆」时读这份。核心主张只有一句：**做内容就是跟一个人聊天**。

## 五个概念的实际分工

| 层级 | 它负责什么 | 一句话检验 |
|---|---|---|
| 内容 | 用户看到、听到、感受到、理解到的**总和**（含标题、封面、评论区） | 它是个容器，不是其中一个零件 |
| 话题 | 讨论的**范围** | 「我想做情感内容」——范围有了，但还是不知道你要讲什么 |
| 选题 | 这次**对谁说、说什么**，必须有具体的人 + 具体的事 | 「对第一次见网友的人，讲怎么让这次约会聊得舒服」 |
| 切入点 | 这次**从哪里开始聊**（入口） | 「从选哪家餐厅开始」 |
| 标题 | 用来**开启这段对话**、最有吸引力的一句话 | 让对的人愿意点进来 |
| 表达 | 怎么把这句话展开成完整叙事 | 知道对方理解到哪，把下一步接给他 |

## 三个最容易漏掉的点

### 1. 切入点要单独成一步

选题决定「说什么」，切入点决定「从哪进来」，两者不是一回事。同一个选题换一个切入点，需要准备的例子、信息和表达顺序都会跟着变。

「第一次约会怎么聊得舒服」这个选题，可以从选餐厅进、可以从一紧张就不断介绍自己进、也可以从约会结束后那条消息进——每一种要准备的东西都不一样。

### 2. 切入点只负责把人带进来

**后面必须回到选题目标。** 如果从「餐厅」切入，整篇都在比较菜系、价格和装修，最后给一份餐厅名单，那它已经变成「第一次约会的餐厅推荐」了，而不是原来那个选题。

所以向导会在用户选了纯信息型入口（误区 / 踩坑 / 对比）时提醒他：这类入口能吸引人进来，但本身不指向结论。

### 3. 词句长什么样，不能决定它属于哪一层

要看它在这次创作里**承担什么结果**。

「第一次约会应该去哪里吃饭」这句话：
- 放在策划阶段，它是**选题**（确定这一篇要解决什么问题）
- 放到用户面前，它就是**标题**

所以不要把某句话绑定到某个字段，要绑定到「它负责什么」。

## 卡住时怎么分流

用户说「这条内容不太行」的时候，先判断卡在哪一层：

| 症状 | 真正卡住的层 | 回到哪一步 |
|---|---|---|
| 打开文档没话说 | 选题不具体 | 第 3 步，把「对谁说什么」写实 |
| 一开口就只能讲大道理 | 没有切入点 | 第 4 步，找一个具体场景 |
| 正文黏黏糊糊 | 表达层：例子、解释、语序不够 | 第 6 步，补齐场景与解释 |
| 想说的都清楚了但没人点 | 标题层力度不够 | 第 5 步 |
| 反复改标题却越改越乱 | 上游根本没定 | 退回第 3、4 步 |

只知道自己想聊情感 / AI / 职场，打开文档就没话说——这是选题问题，改标题没用。

## 顺序不是死的

六步是**检查清单**，不是流水线。真实创作经常是：

- 先想到一句话，觉得很有意思，再围绕它形成选题
- 先遇到一件事，切入点已经摆在眼前，聊着聊着才知道自己最想说什么

把这些拆开，价值在于创作卡住的时候手上有几个具体的地方可以检查，而不是强迫按顺序走。

## 最低启动法

如果对方什么都还没想好，可以让他先写一句：

> 我想跟 ______，聊聊 ______。

然后往下接：我为什么想聊这件事？对方现在最在意哪一部分？我想从哪个例子开始？

这三句说顺了，手上就已经有一份可以继续改的稿子了。
